当前阶段 `job_match` 的调用链：

```text
job_match/router.py
  -> JobMatchService
      -> JobMatchRepository
          -> job_posts / job_post_skills / skills / job_targets / user_skills
```

`JobMatchTextAnalyzer` 和 `JobMatchEmbeddingAnalyzer` 只是后续扩展点，当前 MVP 不启用。

## 7. 哪些功能只是占位，哪些是真的跑通

### 真的跑通的代码路径

- auth 注册、登录、refresh、logout。
- users 当前用户读取。
- ingestion 同步导入、raw 幂等、normalized upsert。
- job_posts 搜索、详情、筛选项缓存。
- job_skills 字典、别名、岗位技能同步 service。
- job_collections 收藏夹、默认收藏夹、收藏恢复和取消。
- job_targets 目标岗位、主目标、状态流转。
- user_skills 技能画像。
- job_match 三个分析接口和集合计算逻辑。

### 只是占位或后续边界

- `study_tasks`：只有 README 和模块边界，缺表、接口、service、repository、tests。
- `knowledge`：只有 README 和模块边界。
- `questions`：只有 README 和模块边界。
- `workers/celery_app.py`：有 Celery 基础 app，但没有完整业务 worker 编排。
- `JobMatchTextAnalyzer` / `JobMatchEmbeddingAnalyzer`：后续 AI/embedding 扩展点，当前不启用。
