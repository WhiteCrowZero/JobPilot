# JobPilot

> **主线：后端业务系统 + 数据导入清洗 + 异步任务协调。**
> 爬虫只是“数据来源之一”，AI 只是“后期增强能力”，MVP 阶段都可以没有。

---

# 一、最终目标：一句话版

**JobPilot 是一个面向求职过程的后端系统，用来管理岗位数据、投递记录、面试复盘和学习任务，并重点体现后端分层、数据库设计、异步任务、缓存、权限、日志、测试和部署能力。**

最终形态不是“爬虫平台”，也不是“AI 平台”，而是：

```text
岗位数据中心
+ 投递流程管理
+ 面试复盘系统
+ 学习任务系统
+ 数据导入清洗能力
+ 后端工程化能力
```

# 三、MVP 阶段核心目标

MVP 阶段只回答一个问题：

> **我能不能做出一个完整、可运行、能讲清楚的后端系统？**

所以 MVP 不追求技术花活，而是追求完整闭环。

## MVP 最终效果

你应该能演示这条流程：

```text
1. 用户注册登录
2. 导入一批岗位数据
3. 系统校验、清洗、去重
4. 用户查看岗位列表
5. 用户收藏 / 投递岗位
6. 用户记录面试复盘
7. 系统根据面试问题生成学习任务
8. 用户查看自己的求职看板
```

这就是一个完整业务闭环。

