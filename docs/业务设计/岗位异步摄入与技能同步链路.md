# JobPilot 阶段需求设计

## 1. 需求名称

需求的名称应该是异步导入链路处理

本阶段的主要任务应该是去负责把爬虫的数据，一个是存到数据库里，然后通过MQ发送这个ID给后端，然后后端来处理这些消息存入数据库

## 2. 背景和问题

当前系统已经具备哪些能力？

包括这个爬虫的能力，数据库存储信息的能力，MQ异步消费任务的能力，主要应该是这三个

现在缺少什么？

现在主要欠缺的应该是爬虫和MQ数据库后端这部分，写好了一部分的解析接口

这个问题会导致什么业务结果无法完成？

现在问题一个就是说，还没有真实的数据来源，用的全都是下载好的静态的模拟数据。第二个就是说，没有构建起来整个的一部消费链路，还是同步的去导入的。所以这样就会导致说整体它的信息来源是一个阻塞的状态。换句话说，整个系统的前半部分是不完善的，和后半部分用户的使用啊，岗位的展示就是隔离开的

## 3. 目标

完成后，用户或系统能够获得什么可观察的结果？

完成之后对用户影响可能就是说，其实看到新的岗位对用户影响不算太大，主要是对系统的影响，能够源源不断地抓取到新的岗位，并且及时地更新，拿到最新的数据
