**PyCharm移动**

先关闭 PyCharm、JetBrains Toolbox、相关后台进程，然后用 PowerShell 执行：

```bash
$src = "C:\Users\wzw\AppData\Local\JetBrains\PyCharm2026.1"
$dst = "D:\tools_dir\JetBrainsData\Local\PyCharm2026.1"
$bak = "C:\Users\wzw\AppData\Local\JetBrains\PyCharm2026.1.bak"

New-Item -ItemType Directory -Force -Path "D:\tools_dir\JetBrainsData\Local" | Out-Null

robocopy $src $dst /MIR /COPYALL /R:1 /W:1

Rename-Item $src $bak

cmd /c mklink /J "$src" "$dst"
```

执行完后检查：

```bash
Get-Item "C:\Users\wzw\AppData\Local\JetBrains\PyCharm2026.1"
```

如果看到类似：

```bash
Mode: d----l
```

或者显示 Junction，说明成功。
然后打开 PyCharm 测试一下。如果能正常启动、插件和缓存没问题，再删除备份：

```bash
Remove-Item "C:\Users\wzw\AppData\Local\JetBrains\PyCharm2026.1.bak" -Recurse -Force
```
