# JobPilot 初始项目说明

## 1. 当前项目定位

当前版本是 JobPilot 的后端 MVP 初始骨架，不做真实爬虫、不做 AI、不做复杂微服务。重点是先把后端基础设施搭好：FastAPI 应用、配置管理、PostgreSQL、Redis、Celery、Alembic、测试目录、Docker Compose 第三方服务。

## 2. Adminer 和 Flower 是什么

Adminer 是一个轻量数据库管理页面，可以在浏览器里查看 PostgreSQL 数据库、表、字段和数据。它不是项目业务服务，只是开发阶段方便你不用额外安装数据库客户端。

Flower 是 Celery 的任务监控页面。后面你做 CSV 异步导入时，Celery worker 会在后台处理任务，Flower 可以查看任务是否执行、是否失败、执行时间等信息。

访问地址：

```txt
Adminer: http://localhost:8080
Flower:  http://localhost:5555
```

## 3. Docker Compose 服务说明

当前 `deploy/docker-compose.yml` 只跑第三方基础服务：

| 服务 | 作用 | 宿主机端口 |
|---|---|---|
| PostgreSQL | 主业务数据库 | 5432 |
| Redis | 缓存、Celery broker、任务结果存储 | 6389 |
| Adminer | 数据库 Web 管理工具 | 8080 |
| Flower | Celery 任务监控工具 | 5555 |

注意：Redis 容器内部端口仍然是 6379，但映射到你电脑上的是 6389，所以本地 `.env` 里 `REDIS_URL` 使用的是 `localhost:6389`。

## 4. 启动顺序

在项目根目录执行：

```bash
uv sync
docker compose --env-file deploy/.env -f deploy/docker-compose.yml up -d
uv run uvicorn job_pilot.main:app --reload
```

检查服务状态：

```bash
docker compose --env-file deploy/.env -f deploy/docker-compose.yml ps
```

访问后端：

```txt
健康检查：http://127.0.0.1:8000/api/v1/health
接口文档：http://127.0.0.1:8000/docs
```

## 5. 数据库连接信息

Adminer 登录时填写：

```txt
System: PostgreSQL
Server: postgres
Username: jobpilot
Password: jobpilot
Database: jobpilot
```

如果你用本机数据库客户端连接，则填写：

```txt
Host: localhost
Port: 5432
Database: jobpilot
User: jobpilot
Password: jobpilot
```

## 6. Redis 连接信息

本机程序连接 Redis：

```txt
Host: localhost
Port: 6389
Password: jobpilot_redis
```

Docker Compose 内部服务连接 Redis：

```txt
Host: redis
Port: 6379
Password: jobpilot_redis
```
